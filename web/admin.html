الان Agent چه وضعیتی دارد؟

این صفحه تست‌های خودکار را از استفاده واقعی جدا می‌کند، پوشش دانش را نشان می‌دهد و تغییرات کتابخانه را قابل فهم می‌کند.

توکن فقط روی همین مرورگر ذخیره می‌شود و در صفحه‌های ادمین همین سایت دوباره استفاده می‌شود.

این نقشه از محتوای نسخه فعال کتاب‌ها ساخته می‌شود. «پوشش قوی» یعنی شواهد بیشتر و متنوع‌تر داریم؛ نه اینکه هر جواب در آن حوزه حتماً درست است.

از آخرین به‌روزرسانی چه دانشی اضافه شد؟

معنی وضعیت جواب‌ها

مستند

Agent برای جواب، مدرک مرتبط در کتاب‌های تأییدشده پیدا کرده است.

مدرک ناکافی

این شکست نیست؛ Agent عمداً جواب قطعی نساخته چون منبع کافی نداشته است.

نیمه‌مستند

بخشی از سؤال مدرک دارد و بخشی هنوز پوشش کافی ندارد.

اختلاف منابع

دو یا چند منبع معتبر دیدگاه متفاوت دارند؛ Agent باید اختلاف را صریح نشان دهد.

«قدرت شواهد» احتمال درست‌بودن جواب نیست؛ فقط نشان می‌دهد شواهد بازیابی‌شده چقدر قوی و معتبر بوده‌اند.
